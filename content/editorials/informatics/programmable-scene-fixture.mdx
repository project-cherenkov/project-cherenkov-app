## What this is

A hand-built fixture, not a real proof-of-error editorial — PROG-004's own
acceptance criterion calls for exactly this: "a hand-built fixture
editorial with a trivial program (e.g., one `emitElement` of a
`shape-circle`) round-trips and renders via a local dev build." This file
is that fixture, committed so the round-trip stays exercised by an ordinary
`pnpm generate` / `pnpm build` rather than a one-off manual check that
nothing re-runs later.

The program itself does the least a `programmable-scene` program can do:
one top-level `emitElement` drawing a single blue circle, no variables, no
control flow, no reader-facing controls.
