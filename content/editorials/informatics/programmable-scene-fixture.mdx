## What this is

A hand-built fixture, not a real proof-of-error editorial. PROG-004's
acceptance criterion calls for exactly this: "a hand-built fixture
editorial with a trivial program (e.g., one `emitElement` of a
`shape-circle`) round-trips and renders via a local dev build." This file
is that fixture. It is committed so that an ordinary `pnpm generate` or
`pnpm build` keeps exercising the round-trip, in place of a one-off manual
check that nothing re-runs later.

The program does the least a `programmable-scene` program can do: one
top-level `emitElement` drawing a single blue circle, with no variables, no
control flow and no reader-facing controls.
